Overview

A wearable interface system designed under one of the tightest constraints in UI design: a screen glanced at for under a second. The project is built entirely around typographic hierarchy and micro-interactions that let critical information register instantly, with no complications competing for attention.

Key Highlights
  • Glanceable hierarchy: Designed a strict typographic hierarchy so the most important information reads first, solving for glanceability rather than density — the defining constraint of wearable UI.
  • Type at watch-face scale: Iterated through multiple type pairings to find a system that stayed legible and cohesive at a few square inches, where small shifts in weight or tracking change the whole read.
  • Motion in service of state: Added micro-interactions only after the static hierarchy was solid, using animation specifically to soften state changes rather than to decorate the interface.
Challenge

A watch face gets a glance, not a read — the interface has to communicate its full hierarchy in well under a second, on a screen a fraction the size of a phone's, with no room for a second pass. The challenge was building a spatial and typographic hierarchy that resolves instantly without feeling cluttered or under-designed.

Approach

Iterated through type pairings and spatial arrangements to find a hierarchy that reads in a single glance, prioritizing weight and placement over ornamentation. Layered in micro-interactions only after that hierarchy held up on its own, using motion to soften state changes rather than to carry information the static layout should already communicate.
